# 从零创建 my-ui-library 并生成 registry

按以下两步创建 shadcn 项目并生成 registry。

## 第一步：创建 shadcn 项目

运行以下命令：

```bash
pnpm create next-app my-ui-library
cd my-ui-library
pnpm dlx shadcn@latest init
pnpm dlx shadcn@latest add --all
```

`create-next-app` 提示项目配置时，选择以下值：

| 提示项 | 选择 | 配置依据 |
| --- | --- | --- |
| 项目名称 | `my-ui-library` | 创建命令和 `package.json` |
| 推荐默认设置 | 选择自定义设置 | 项目使用 Biome、React Compiler 和 `src/` 目录 |
| TypeScript | 是 | `tsconfig.json` 和 `.ts`、`.tsx` 源码 |
| 代码检查工具 | Biome | `package.json` 的 `lint`、`format` 命令和 Biome 依赖 |
| React Compiler | 是 | `next.config.ts` 中的 `reactCompiler: true` |
| Tailwind CSS | 是 | `tailwindcss` 依赖和 `src/app/globals.css` |
| `src/` 目录 | 是 | App Router 文件位于 `src/app/` |
| App Router | 是 | 页面和布局位于 `src/app/` |
| Cache Components | 是 | `next.config.ts` 中的 `cacheComponents: true` |
| 导入别名 | 保留默认值 `@/*` | `tsconfig.json` 中的 `paths` 配置 |
| `AGENTS.md` | 包含 | 项目根目录有 `AGENTS.md` |

项目使用 Next.js 16.4.6、React 19、Tailwind CSS 4 和 pnpm 12.17.0。`package.json` 固定 pnpm 版本。

`shadcn init` 提示配置时，选择下表中的值。配置保存在 `components.json`。

| 设置 | 值 |
| --- | --- |
| Style | `radix-nova` |
| Base color | `neutral` |
| CSS variables | 启用 |
| CSS 文件 | `src/app/globals.css` |
| Icon library | `lucide` |
| React Server Components | 启用 |
| TSX | 启用 |
| RTL | 关闭 |
| Components alias | `@/components` |
| UI alias | `@/components/ui` |
| Lib alias | `@/lib` |
| Hooks alias | `@/hooks` |
| Utils alias | `@/lib/utils` |
| Menu color | `default` |
| Menu accent | `subtle` |

安装依赖并启动项目：

```bash
pnpm install
pnpm dev
```

`pnpm dev` 在 `http://localhost:3000` 启动开发服务器。项目使用 Biome 检查和格式化代码。

## 第二步：生成 registry

`scripts/generate-registry.mjs` 扫描 `src/components/ui/*.tsx`，提取项目依赖，并生成根目录的 `registry.json`。标题由组件文件名生成，描述使用组件标题和项目名称。项目不使用 metadata 文件。

### 本次新增和修改的文件

| 文件或目录 | 操作 | 改动内容 |
| --- | --- | --- |
| `package.json` | 修改 | 添加 `registry:generate`、`registry:validate` 和 `registry:build` 命令；build 前自动校验 |
| `scripts/generate-registry.mjs` | 新增 | 扫描组件，提取 npm 和项目内依赖，生成 registry 条目 |
| `scripts/validate-registry.mjs` | 新增 | 检查 registry 字段、组件文件及依赖引用 |
| `registry.json` | 生成 | 包含 63 个 UI 组件的 registry 定义 |
| `public/r/registry.json`、`public/r/*.json` | 生成 | 静态 registry 目录和 63 个可安装条目 |

### 生成和验证 registry

生成并构建静态 registry：

```bash
pnpm registry:generate
pnpm registry:build
```

`registry:build` 会先运行校验，再执行 `shadcn build`。单独检查现有 registry 时，运行 `pnpm registry:validate`。

`registry:generate` 会覆盖根目录的 `registry.json`。默认 homepage 是 `http://localhost:3000`，组件依赖使用相对 JSON 地址。`registry:build` 会生成 `public/r/registry.json` 和 `public/r/<组件名>.json`，Next.js 会从 `/r/...` 提供这些文件。

为线上静态 registry 设置实际主页地址：

```bash
pnpm registry:generate -- --homepage https://ui.example.com
pnpm registry:build
```

修改 UI 组件后，重新运行生成和构建命令。不要直接编辑生成的 `registry.json`。需要调整默认标题或描述时，修改 `scripts/generate-registry.mjs`。

### 在本地查看静态 registry

在另一个项目目录中检查或安装组件：

```bash
pnpm dlx shadcn@latest list http://localhost:3000/r/registry.json
pnpm dlx shadcn@latest view http://localhost:3000/r/button.json
pnpm dlx shadcn@latest add http://localhost:3000/r/button.json
```

先在本项目运行 `pnpm dev`，再从安装方项目运行以上命令。安装项目需要配置 shadcn，并包含组件使用的主题变量。

### 使用公开 GitHub 仓库分发

也可以直接从公开 GitHub 仓库分发。生成清单时传入仓库地址：

```bash
pnpm registry:generate -- --github your-github-name/my-ui-library
```

将 `your-github-name` 换成 GitHub 用户名。脚本会把组件依赖写成 `owner/repo/item` 地址，并将 homepage 设为仓库地址。提交 `registry.json` 后，安装方运行：

```bash
pnpm dlx shadcn@latest list your-github-name/my-ui-library
pnpm dlx shadcn@latest add your-github-name/my-ui-library/button
```

GitHub registry 直接读取仓库中的 `registry.json`，不需要运行 `pnpm registry:build`。私有仓库要求安装方有读取权限。

```js
#!/usr/bin/env node

import fs from "node:fs/promises"
import path from "node:path"
import process from "node:process"
import ts from "typescript"

const root = process.cwd()
const sourceRoot = path.join(root, "src")
const uiRoot = path.join(sourceRoot, "components", "ui")
const packageJson = JSON.parse(
  await fs.readFile(path.join(root, "package.json"), "utf8")
)

function parseOptions(args) {
  const options = {}

  for (let index = 0; index < args.length; index += 1) {
    const arg = args[index]

    if (arg === "--github" || arg === "--homepage") {
      const value = args[index + 1]
      if (!value || value.startsWith("--")) {
        throw new Error(`Missing value for ${arg}`)
      }
      options[arg.slice(2)] = value
      index += 1
      continue
    }

    throw new Error(`Unknown option: ${arg}`)
  }

  return options
}

function toPosix(value) {
  return value.split(path.sep).join("/")
}

function isInside(parent, candidate) {
  const relative = path.relative(parent, candidate)
  return relative === "" || (!relative.startsWith("..") && !path.isAbsolute(relative))
}

function getItemName(filePath) {
  return path.basename(filePath, path.extname(filePath))
}

function getTitle(name) {
  return name
    .split("-")
    .map((part) => part.charAt(0).toUpperCase() + part.slice(1))
    .join(" ")
}

function getRegistryFile(filePath) {
  const relativeToSrc = toPosix(path.relative(sourceRoot, filePath))
  const segments = relativeToSrc.split("/")

  if (relativeToSrc.startsWith("components/ui/")) {
    return {
      path: toPosix(path.relative(root, filePath)),
      type: "registry:ui",
      target: `@ui/${segments.slice(2).join("/")}`,
    }
  }

  if (relativeToSrc.startsWith("components/")) {
    return {
      path: toPosix(path.relative(root, filePath)),
      type: "registry:component",
      target: `@components/${segments.slice(1).join("/")}`,
    }
  }

  if (relativeToSrc.startsWith("hooks/")) {
    return {
      path: toPosix(path.relative(root, filePath)),
      type: "registry:hook",
      target: `@hooks/${segments.slice(1).join("/")}`,
    }
  }

  if (relativeToSrc.startsWith("lib/")) {
    return {
      path: toPosix(path.relative(root, filePath)),
      type: "registry:lib",
      target: `@lib/${segments.slice(1).join("/")}`,
    }
  }

  return {
    path: toPosix(path.relative(root, filePath)),
    type: "registry:file",
    target: `~/src/${relativeToSrc}`,
  }
}

function collectModuleSpecifiers(filePath) {
  const source = ts.createSourceFile(
    filePath,
    ts.sys.readFile(filePath) ?? "",
    ts.ScriptTarget.Latest,
    true,
    filePath.endsWith(".tsx") ? ts.ScriptKind.TSX : ts.ScriptKind.TS
  )
  const specifiers = new Set()

  function visit(node) {
    if (
      (ts.isImportDeclaration(node) || ts.isExportDeclaration(node)) &&
      node.moduleSpecifier &&
      ts.isStringLiteral(node.moduleSpecifier)
    ) {
      specifiers.add(node.moduleSpecifier.text)
    }

    if (
      ts.isCallExpression(node) &&
      node.expression.kind === ts.SyntaxKind.ImportKeyword &&
      node.arguments.length === 1 &&
      ts.isStringLiteral(node.arguments[0])
    ) {
      specifiers.add(node.arguments[0].text)
    }

    ts.forEachChild(node, visit)
  }

  visit(source)
  return [...specifiers]
}

function getPackageName(specifier) {
  if (specifier.startsWith("node:")) return null
  if (specifier.startsWith("@/")) return null

  const parts = specifier.split("/")
  return specifier.startsWith("@") ? parts.slice(0, 2).join("/") : parts[0]
}

function addPackageDependency(specifier, dependencies, devDependencies) {
  const packageName = getPackageName(specifier)
  if (!packageName || ["react", "react-dom", "next"].includes(packageName)) {
    return
  }

  const version = packageJson.dependencies?.[packageName]
  if (version) {
    dependencies.add(`${packageName}@${version}`)
    return
  }

  const devVersion = packageJson.devDependencies?.[packageName]
  if (devVersion) {
    devDependencies.add(`${packageName}@${devVersion}`)
    return
  }

  dependencies.add(packageName)
}

const options = parseOptions(process.argv.slice(2))
let githubRepository = null

if (options.github) {
  const parts = options.github.split("/").filter(Boolean)
  if (parts.length !== 2) {
    throw new Error("--github must use the owner/repository format")
  }
  githubRepository = parts.join("/")
}

const configPath = path.join(root, "tsconfig.json")
const configFile = ts.readConfigFile(configPath, ts.sys.readFile)
if (configFile.error) {
  throw new Error(ts.flattenDiagnosticMessageText(configFile.error.messageText, "\n"))
}
const parsedConfig = ts.parseJsonConfigFileContent(
  configFile.config,
  ts.sys,
  root
)

const componentPaths = (await fs.readdir(uiRoot))
  .filter((fileName) => fileName.endsWith(".tsx"))
  .map((fileName) => path.join(uiRoot, fileName))
  .sort()

if (componentPaths.length === 0) {
  throw new Error(`No .tsx components found in ${path.relative(root, uiRoot)}`)
}

const componentNames = new Map(
  componentPaths.map((filePath) => [path.resolve(filePath), getItemName(filePath)])
)
const packageItems = []

for (const componentPath of componentPaths) {
  const name = getItemName(componentPath)
  const localFiles = new Map()
  const componentDependencies = new Set()
  const dependencies = new Set()
  const devDependencies = new Set()
  const visited = new Set()

  function resolveImport(specifier, containingFile) {
    const result = ts.resolveModuleName(
      specifier,
      containingFile,
      parsedConfig.options,
      ts.sys
    ).resolvedModule

    if (result?.resolvedFileName && !result.isExternalLibraryImport) {
      const resolvedPath = path.resolve(result.resolvedFileName)
      if (isInside(sourceRoot, resolvedPath)) return resolvedPath
    }

    if (specifier.startsWith(".") || specifier.startsWith("@/")) {
      throw new Error(`Could not resolve local import "${specifier}" in ${path.relative(root, containingFile)}`)
    }

    return null
  }

  function analyzeFile(filePath) {
    const normalizedPath = path.resolve(filePath)
    if (visited.has(normalizedPath)) return
    visited.add(normalizedPath)

    for (const specifier of collectModuleSpecifiers(normalizedPath)) {
      const resolvedPath = resolveImport(specifier, normalizedPath)

      if (!resolvedPath) {
        addPackageDependency(specifier, dependencies, devDependencies)
        continue
      }

      if (componentNames.has(resolvedPath)) {
        if (resolvedPath !== path.resolve(componentPath)) {
          componentDependencies.add(componentNames.get(resolvedPath))
        }
        continue
      }

      if (!localFiles.has(resolvedPath)) {
        localFiles.set(resolvedPath, getRegistryFile(resolvedPath))
      }
      analyzeFile(resolvedPath)
    }
  }

  analyzeFile(componentPath)

  const registryDependencies = [...componentDependencies]
    .sort()
    .map((dependency) =>
      githubRepository
        ? `${githubRepository}/${dependency}`
        : `./${dependency}.json`
    )

  const item = {
    name,
    type: "registry:ui",
    title: getTitle(name),
    description: `${getTitle(name)} component from ${packageJson.name}.`,
    files: [
      getRegistryFile(componentPath),
      ...[...localFiles.values()].sort((left, right) =>
        left.path.localeCompare(right.path)
      ),
    ],
  }

  if (registryDependencies.length > 0) {
    item.registryDependencies = registryDependencies
  }
  if (dependencies.size > 0) {
    item.dependencies = [...dependencies].sort()
  }
  if (devDependencies.size > 0) {
    item.devDependencies = [...devDependencies].sort()
  }

  packageItems.push(item)
}

const homepage =
  options.homepage ??
  (githubRepository
    ? `https://github.com/${githubRepository}`
    : packageJson.homepage ?? "http://localhost:3000")

const registry = {
  $schema: "https://ui.shadcn.com/schema/registry.json",
  name: packageJson.name,
  homepage,
  items: packageItems,
}

const outputPath = path.join(root, "registry.json")
await fs.writeFile(outputPath, `${JSON.stringify(registry, null, 2)}\n`)

console.log(
  `Generated registry.json with ${packageItems.length} items from ${path.relative(root, uiRoot)}.`
)
console.log(
  githubRepository
    ? `GitHub dependencies target ${githubRepository}.`
    : "Relative item dependencies are configured for static hosting."
)
```

```js
#!/usr/bin/env node

import fs from "node:fs/promises"
import path from "node:path"
import process from "node:process"

const root = process.cwd()
const registryPath = path.join(root, "registry.json")
const packageJson = JSON.parse(
  await fs.readFile(path.join(root, "package.json"), "utf8")
)
const errors = []

function isInside(parent, candidate) {
  const relative = path.relative(parent, candidate)
  return relative === "" || (!relative.startsWith("..") && !path.isAbsolute(relative))
}

function getPackageName(dependency) {
  const versionSeparator = dependency.startsWith("@")
    ? dependency.indexOf("@", dependency.indexOf("/") + 1)
    : dependency.indexOf("@")

  return versionSeparator === -1
    ? dependency
    : dependency.slice(0, versionSeparator)
}

function getLocalRegistryDependencyName(dependency) {
  if (dependency.startsWith("./") && dependency.endsWith(".json")) {
    return path.basename(dependency, ".json")
  }

  const githubDependency = dependency.split("#")[0].split("/")
  if (githubDependency.length === 3 && !dependency.startsWith("http")) {
    return githubDependency[2]
  }

  return null
}

function addError(message) {
  errors.push(message)
}

let registry
try {
  registry = JSON.parse(await fs.readFile(registryPath, "utf8"))
} catch (error) {
  console.error(`Registry validation failed: ${error.message}`)
  process.exit(1)
}

if (registry.$schema !== "https://ui.shadcn.com/schema/registry.json") {
  addError('registry.json has an invalid "$schema" value')
}
if (typeof registry.name !== "string" || registry.name.trim() === "") {
  addError('registry.json must define a non-empty "name"')
}
if (typeof registry.homepage !== "string" || registry.homepage.trim() === "") {
  addError('registry.json must define a non-empty "homepage"')
} else {
  try {
    new URL(registry.homepage)
  } catch {
    addError(`registry.json has an invalid homepage URL: ${registry.homepage}`)
  }
}
if (!Array.isArray(registry.items) || registry.items.length === 0) {
  addError('registry.json must contain a non-empty "items" array')
}

if (errors.length > 0) {
  console.error(`Registry validation failed with ${errors.length} error(s):`)
  for (const error of errors) console.error(`- ${error}`)
  process.exit(1)
}

const itemNames = new Set()
const itemsByName = new Map()

for (const item of registry.items) {
  if (!item || typeof item !== "object" || Array.isArray(item)) {
    addError("A registry item must be a JSON object")
    continue
  }

  if (typeof item.name !== "string" || item.name.trim() === "") {
    addError("A registry item has no valid name")
    continue
  }

  if (!/^[a-z0-9]+(?:-[a-z0-9]+)*$/.test(item.name)) {
    addError(`Item "${item.name}" must use lowercase kebab-case`)
  }
  if (itemNames.has(item.name)) {
    addError(`Duplicate registry item name: ${item.name}`)
  }
  itemNames.add(item.name)
  itemsByName.set(item.name, item)

  if (item.type !== "registry:ui") {
    addError(`Item "${item.name}" must use type "registry:ui"`)
  }
  if (typeof item.title !== "string" || item.title.trim() === "") {
    addError(`Item "${item.name}" has no title`)
  }
  if (typeof item.description !== "string" || item.description.trim() === "") {
    addError(`Item "${item.name}" has no description`)
  }
  if (!Array.isArray(item.files) || item.files.length === 0) {
    addError(`Item "${item.name}" has no files`)
  }

  let hasPrimaryComponent = false
  const files = Array.isArray(item.files) ? item.files : []
  for (const file of files) {
    if (!file || typeof file !== "object" || Array.isArray(file)) {
      addError(`Item "${item.name}" has an invalid file entry`)
      continue
    }

    if (typeof file.path !== "string" || file.path.trim() === "") {
      addError(`Item "${item.name}" has a file without a path`)
      continue
    }

    const filePath = path.resolve(root, file.path)
    if (!isInside(root, filePath)) {
      addError(`Item "${item.name}" references a file outside the project: ${file.path}`)
      continue
    }

    try {
      const stat = await fs.stat(filePath)
      if (!stat.isFile()) {
        addError(`Item "${item.name}" file path is not a file: ${file.path}`)
      }
    } catch {
      addError(`Item "${item.name}" references a missing file: ${file.path}`)
    }

    if (
      file.path === `src/components/ui/${item.name}.tsx` &&
      file.type === "registry:ui"
    ) {
      hasPrimaryComponent = true
    }
    if (typeof file.target !== "string" || file.target.trim() === "") {
      addError(`Item "${item.name}" file has no target: ${file.path}`)
    }
  }
  if (!hasPrimaryComponent) {
    addError(`Item "${item.name}" has no matching primary UI component file`)
  }

  if (item.dependencies !== undefined && !Array.isArray(item.dependencies)) {
    addError(`Item "${item.name}" dependencies must be an array`)
  } else {
    for (const dependency of item.dependencies ?? []) {
      if (typeof dependency !== "string" || dependency.trim() === "") {
        addError(`Item "${item.name}" has an invalid npm dependency`)
        continue
      }

      const dependencyName = getPackageName(dependency)
      if (
        !packageJson.dependencies?.[dependencyName] &&
        !packageJson.devDependencies?.[dependencyName]
      ) {
        addError(
          `Item "${item.name}" uses "${dependencyName}", which is missing from package.json`
        )
      }
    }
  }

  if (item.registryDependencies !== undefined && !Array.isArray(item.registryDependencies)) {
    addError(`Item "${item.name}" registryDependencies must be an array`)
    continue
  }
  for (const dependency of item.registryDependencies ?? []) {
    if (typeof dependency !== "string" || dependency.trim() === "") {
      addError(`Item "${item.name}" has an invalid registry dependency`)
      continue
    }

  }
}

const componentPaths = (await fs.readdir(path.join(root, "src/components/ui")))
  .filter((fileName) => fileName.endsWith(".tsx"))
  .sort()
const componentNames = new Set(
  componentPaths.map((fileName) => path.basename(fileName, ".tsx"))
)

for (const componentName of componentNames) {
  if (!itemsByName.has(componentName)) {
    addError(`Component "${componentName}" is missing from registry.json`)
  }
}
for (const itemName of itemNames) {
  if (!componentNames.has(itemName)) {
    addError(`Registry item "${itemName}" has no source component`)
  }
}
for (const item of registry.items) {
  for (const dependency of item.registryDependencies ?? []) {
    const localDependencyName = getLocalRegistryDependencyName(dependency)
    if (localDependencyName && !itemsByName.has(localDependencyName)) {
      addError(
        `Item "${item.name}" depends on missing registry item "${localDependencyName}"`
      )
    }
  }
}

if (errors.length > 0) {
  console.error(`Registry validation failed with ${errors.length} error(s):`)
  for (const error of errors) console.error(`- ${error}`)
  process.exit(1)
}

console.log(`Registry validation passed: ${registry.items.length} items.`)
```
